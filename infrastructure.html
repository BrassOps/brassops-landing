Overview

Architecture

BrassOps is a modern full-stack web application built for performance, security, and scale. Multi-tenant by design with row-level security, real-time data, and AI-powered analysis.

Stack

Tech Stack

Every layer of BrassOps — from the framework to the hosting edge.

Next.js 16

Framework

App Router, React 19, TypeScript strict mode. Server and client components. API routes for all mutations.

React 19

UI Library

Latest React with server components, concurrent features, and streaming SSR.

TypeScript

Language

Strict mode enforced. Zero type errors at build time. Full type coverage across 79 source files.

Tailwind CSS 4

Styling

Utility-first CSS with custom dark theme. Glass morphism design system with 17 reusable components.

Supabase

Database & Auth & Storage

PostgreSQL database with Row-Level Security for multi-tenant data isolation. Built-in auth, real-time subscriptions, file storage.

Claude AI (Anthropic)

AI / Computer Vision

Vision API for target analysis. Automatic bullet hole detection and shot group grading from uploaded target photos.

Recharts

Data Visualization

React charting library. Powers all analytics dashboards — bar charts, radar charts, pie charts, line charts.

SMTP2GO

Email

Transactional email delivery. Flagged officer alerts, remedial follow-up reminders, automated notifications.

Vercel

Hosting & CI/CD

Edge-optimized hosting with automatic deployments from GitHub. Global CDN, serverless functions, preview deployments.

GitHub

Version Control

Source control, issue tracking, CI integration. Private repository under the BrassOps organization.

Hardened

Security

Defense-in-depth measures protecting every layer of the platform.

  • Row-Level Security on all data tables
  • Agency-scoped data isolation
  • IDOR protection on all API endpoints
  • XSS prevention with HTML escaping
  • Security headers (X-Frame-Options, CSP, HSTS)
  • File upload validation and size limits
  • Input validation and enum enforcement
  • Error message sanitization
  • CSV formula injection prevention
