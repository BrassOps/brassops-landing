Email signature

  1. Click Copy signature below (or select everything in the white box and copy).
  2. In Gmail: Settings (gear), See all settings, General, Signature.
  3. Click into your signature, select all of it, paste, then click Save Changes at the bottom of the page.

Brevo automation emails

  1. In Brevo: Automations, open the workflow, click the email step, then Edit design.
  2. Click the old sign-off ("Rich, BrassOps, Founder") and delete that block.
  3. From the content blocks on the left, drag an HTML block into the same spot.
  4. Click Copy code for Brevo below, paste it into the HTML block, then save the email.
